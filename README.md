# File Share App

Developed a full-stack file-sharing platform using React, Vite, Tailwind CSS, and Clerk for secure user experience, with Java 21 and Spring Boot powering RESTful backend APIs, MongoDB for transaction storage, Razorpay for subscription payments and credit purchases, and credit-based file uploads, downloads, public sharing, and transaction tracking.
